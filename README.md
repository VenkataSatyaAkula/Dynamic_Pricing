
# Dynamic Pricing Optimization for E-Commerce

A machine learning web app that predicts the optimal selling price of a product from its details.

**Live demo:** https://satya6844.pythonanywhere.com/

## Features
- Predicts price using a Linear Regression model
- Inputs: product ID, category, quantity, freight price, number of photos, previous price
- Features are scaled before prediction
- Simple Flask web interface

## Tech Stack
Python, NumPy, Flask, HTML, CSS, JavaScript, Jupyter Notebook

## Files
- `1.retail_price.csv` - dataset
- `2.mini.ipynb.ipynb` - data analysis and model training
- `3.retail_linear_regression.pkl` - trained model
- `4.scaler.pkl` - feature scaler
- `5.flask_app.py` - Flask app
